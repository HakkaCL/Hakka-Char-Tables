惠陽有兩張表：**淡水**（縣志 2003）與 **1987**（周日健）不是同一土語——前者泥來合流、遇三讀 iu，後者 n／l 對立、遇三讀 u，故分立並列。

## 各點特點

- **大埔百侯**：原書簡體，已轉繁體，一簡對多繁按釋義判定；另收教育部《臺灣客家語書寫推薦用字》兩批，`來源` 欄標批次與編號。
- **深圳寶安**：字形照母本；有音位性 /j/；流攝讀 iu（頭 `tiu2`）。
- **惠陽淡水**：縣志詞表逐字對位；泥來合流（腦 `lau3`）、遇三讀 iu（豬 `ziu1`）、三四等無 i 介音（天 `ten1`）。
- **惠陽 1987**：周日健單音節表；泥母讀 n（腦 `nau3`）、遇三讀 u（書 `su1`）、三四等作 ian（天 `tian1`）。
- **惠東大嶺**：《通用詞典》「惠」欄為主，另以周日健 1994 補 67 字、訂正 3 條。
- **香港新界**：協會原表用 1–6 調，已按調類換算為 1、2、3、5、7、8；有音位性 /j/；三四等保留 i 介音（天 `tien1`）、流攝讀 eu（頭 `teu2`）。
- **興寧**：同音字表逐頁對圖校正，原書簡體已轉繁體；六調，舌尖後音寫 `zh ch sh rh`，`ɿ` 寫 `ii`、`ʅ` 寫 `i`（知 `zhi1`、資 `zii1`）。
- **長汀**：原書簡體已轉繁體；五調（陰去 5、陽去 6，無入聲）；`j q x` 與 `zh ch sh` 分立；`o`／`oo` 依方案分立（`oo` = [ɔ]，故 `ioong` 對梅惠 `iong`、`iong` 對梅惠 `iung`）。
