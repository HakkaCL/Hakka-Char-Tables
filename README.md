# Hakka Char Tables｜客家字音表

客家方言的漢字讀音表，供檢索、比較與再利用。目前收錄一個方言點：**大埔百侯**（廣東梅州大埔百侯鎮）。

## 收錄

| 方言點 | 條目 | 字數 | 內容 |
|---|---:|---:|---|
| `data/dabu-baihou/` | 3,688 | 3,366 | 字、碼位、客拼、聲韻調、IPA、來源、註釋 |

讀音有兩個來源，表內「來源」欄逐行標明：

- `詞典`——由《客家方言詞典》（何耿鏞，2012）整理
- `母語者表`——母語者田調

## 檔案

| 檔 | 內容 |
|---|---|
| `data/dabu-baihou/大埔百侯-完整表.tsv` | 主表，九欄 |
| `data/dabu-baihou/大埔百侯.tsv` | 三欄精簡版（字／音標／註釋），便於匯入 |
| `docs/schema.md` | 欄位定義與客拼方案 |

## 客拼方案

聲調 1–8（1 陰平、2 陽平、3 上、5 去、7 陰入、8 陽入）；`b/p`＝不送氣/送氣，`ee`＝[æ]，`ii`＝[ɿ]，齊齒前的 [h] 寫 `x`（[ç]）。詳見 [schema](docs/schema.md)。
