## 欄位

`字 UCODE 客拼 聲母 韻母 聲調 音標 來源 註釋`，見 [`docs/schema.md`](docs/schema.md)。

## 客拼

採用臺灣《客家語拼音方案》的聲母、韻母寫法，聲調按四聲八調以 1–8 標記。各點皆無陽上、陽去，實際只用 1、2、3、5、7、8。

各點另有少量處理：

- 大埔百侯：齊齒前的 [ç] 寫 `x`；`æ` 寫 `ee`
- 深圳寶安：有音位性 /j/，客拼方案無 y 字母，記作零聲母的 i 韻頭（一 `id7`、爺 `ia2`）
- 惠陽淡水、惠東大嶺：零聲母不加字母（愛 `oi5`、有 `iu1`）
- 惠陽 1987：同淡水寫法，另有 `ian`／`iad`（天 `tian1`、乙 `iad7`）
- 香港新界：有音位性 /j/，記作零聲母的 i 韻頭（一 `id7`、有 `iu1`）；ɿ 併入 u（資 `zu1`）；三四等保留 `ien`／`ied`；流攝 `eu`（頭 `teu2`）

## 音標

IPA，與客拼逐欄對應，聲調同用 1–8 調類代號。`e`、`o` 記音位／e／／o／，實際音值近 [ɛ]、[ɔ]。
