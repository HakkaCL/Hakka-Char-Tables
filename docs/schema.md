## 客拼方案

採用臺灣《客家語拼音方案》的聲母、韻母寫法；聲調按四聲八調以 1–8 標記——平、上、去、入各分陰陽。各點皆無陽上、陽去，實際用 1、2、3、5、7、8。

共用部分：

- 聲母：`b p m f v / d t n l / g k ng h / z c s`（大埔另有 `zh ch sh rh`、齊齒前的 `x`）
- 韻尾：`-m -n -ng` 與 `-b -d -g`
- 通攝 `ung/ug`、宕攝 `ong/og`
- 聲化韻 `m`、`ng`

逐點處理：

| 點 | 處理 |
|---|---|
| 大埔百侯 | 齊齒前的 [ç] 寫 `x`；`ee` 為 [ɛ]；`ii` 為舌尖元音；`er` 為 [ə] |
| 深圳寶安 | 方案無 y，音位性 /j/ 記作零聲母的 i 韻頭（一 `id7`、爺 `ia2`、用 `iung3`）；ɿ 已併入 u，一律寫 `u`（資 `zu1`） |
| 惠陽淡水 | ɿ 寫 `ii`（資 `zii1`）；零聲母不加字母（愛 `oi5`） |
| 惠陽 1987 | 同上；另有 `ian`／`iad`（原書 ian／iat），天 `tian1`、乙 `iad7` |
| 惠東大嶺 | 零聲母不加字母；原書 `ɛ`／`ɔ` 依其音系表統一作 `e`／`o` |
| 香港新界 | 方案無 y，音位性 /j/ 記作零聲母的 i 韻頭（一 `id7`、有 `iu1`、音 `im1`）；ɿ 併入 u（資 `zu1`）；三四等保留 `ien`／`ied`（天 `tien1`、月 `ngied8`）；流攝 `eu`（頭 `teu2`） |

## 音標

IPA，與客拼逐欄對應，聲調同用 1–8 調類代號。寶安、惠陽、惠東、香港新界四點的 `e`、`o` 記音位／e／／o／，實際音值近 [ɛ]、[ɔ]。
