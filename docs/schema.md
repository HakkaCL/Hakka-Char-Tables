## 客拼方案

採用臺灣《客家語拼音方案》的聲母、韻母寫法；聲調按四聲八調以 1–8 標記——平、上、去、入各分陰陽，本點無陽上、陽去，實際用 1、2、3、5、7、8。

- 聲母：`b p m f v / d t n l / g k ng h / z c s / zh ch sh rh`
- 齊齒前的 [ç] 寫 `x`：喜 `xi3`、兄 `xiung1`
- `ii` 為舌尖元音 [ɿ]/[ʅ]；`ee` 為 [ɛ]；`er` 為 [ə]
- 聲化韻 `m`、`ng`

## 音標

IPA，與客拼逐欄對應。聲調同用 1–8。
