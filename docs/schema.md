# 欄位與記音規則

各方言點大致共用同一套欄位與客拼方案；差別在「來源」的取值、字形處理、少量逐點記音，以及深圳寶安、香港新界暫用的 `y` 聲母（見下）。表清單與規模見 [README](../README.md)。

## 欄位

一行一個「字—讀音」。同字多讀分行，讀音不同即不同行。TSV、UTF-8（無 BOM）、LF，首行為欄名。

| 欄 | 說明 | 例 |
|---|---|---|
| 字 | 單字；字形處理見下 | 東 |
| UCODE | 碼位 | U+6771 |
| 客拼 | 臺灣《客家語拼音方案》，聲調 1–8（深圳寶安、香港新界暫加 `y`，見下） | dung1 |
| 聲母／韻母／聲調 | 由客拼切分；零聲母、聲化韻的聲母留空 | d／ung／1 |
| 音標 | IPA，末尾接 1–8 調類代號 | tuŋ1 |
| 來源 | 見下；同條多來源以「、」並列 | 詞典、母語者表 |
| 註釋 | 例詞、用字說明；`~` 代本字 | ~人、~常 |

## 客拼方案

採用臺灣《客家語拼音方案》的聲母、韻母寫法；聲調按四聲八調以 1–8 標記——平、上、去、入各分陰陽。各點皆無陽上、陽去，實際用 1、2、3、5、7、8。深圳寶安、香港新界暫以 `y` 表 /j/，其餘各點不變。

共用部分：

- 聲母：`b p m f v / d t n l / g k ng h / z c s`（大埔另有 `zh ch sh rh`、齊齒前的 `x`；深圳寶安、香港新界暫加 `y`）
- 韻尾：`-m -n -ng` 與 `-b -d -g`
- 通攝 `ung/ug`、宕攝 `ong/og`
- 聲化韻 `m`、`ng`

逐點處理：

| 點 | 處理 |
|---|---|
| 大埔百侯 | 齊齒前的 [ç] 寫 `x`；`ee` 為 [ɛ]；`ii` 為舌尖元音；`er` 為 [ə]；`v` 為聲化韻 [v̩]（侮 `v3`） |
| 深圳寶安 | 暫用 `y` 聲母：音位性 /j/ 寫 `y`（一 `yid7`、有 `yiu1`、爺 `yia2`、用 `yiung3`）；香港新界同；其餘各點仍依方案不用 `y` |
| 惠陽淡水 | ɿ 寫 `ii`（資 `zii1`）；零聲母不加字母（愛 `oi5`） |
| 惠陽 1987 | 同上；另有 `ian`／`iad`（原書 ian／iat），天 `tian1`、乙 `iad7` |
| 惠東大嶺 | 零聲母不加字母；原書 `ɛ`／`ɔ` 依其音系表統一作 `e`／`o` |
| 香港新界 | 暫用 `y` 聲母（與寶安同）：音位性 /j/ 寫 `y`（一 `yid7`、有 `yiu1`、音 `yim1`）；三四等保留 `ien`／`ied`（天 `tien1`、月 `ngied8`）；流攝 `eu`（頭 `teu2`）；其餘各點仍不用 `y` |
| 興寧 | 舌尖後音 `tʂ tʂ' ʂ ʐ` 依方案寫 `zh ch sh rh`；`ɿ` 寫 `ii`（資 `zii1`）、`ʅ` 寫 `i`（知 `zhi1`）；`ɔ` 寫 `o`；調類 4→5、5→7、6→8 |
| 長汀 | `j q x` = [tɕ tɕʰ ɕ] 與 `zh ch sh` = [tʃ tʃʰ ʃ] 分立，均照方案原用；**`o`／`oo` 分立**（`o`=[o]、`oo`=[ɔ]，故 `ɑo`→`oo`、`iɑo`→`ioo`、`ônɡ`→`oong`、`iônɡ`→`ioong`）；`ï` 寫 `ii`；調類 4→5、5→6（無入聲，7／8 空） |

## 音標

IPA，與客拼逐欄對應；末尾的數字是**調類**（1–8），不是調值。各點的聲母、韻母、調值見該點 README。長汀 `o`、`oo` 依方案分立（[o]、[ɔ]），與其餘各點「`o` 記 [ɔ]」不同，跨表比較時須換算。寶安、惠陽、惠東、香港新界四點的 `e`、`o` 記音位／e／／o／，實際音值近 [ɛ]、[ɔ]。
