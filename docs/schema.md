# 欄位定義

## data/<方言點>/<方言點>-完整表.tsv

主表，一行一個「字—讀音」。

| 欄 | 說明 | 例 |
|---|---|---|
| 字 | 繁體單字 | 東 |
| UCODE | 碼位 | U+6771 |
| 客拼 | 方言羅馬字（本庫方案，聲調 1–8） | dung1 |
| 聲母 / 韻母 / 聲調 | 由客拼切分；零聲母與聲化韻的聲母留空 | d / ung / 1 |
| 音標 | IPA | toŋ1 |
| 來源 | `詞典`／`母語者表`／兩者並列 | 詞典、母語者表 |
| 註釋 | 例詞、用字說明；`~` 代本字 | ~人、~常 |

客拼方案要點：`b/p`＝不送氣/送氣，`ee`＝[æ]，`ii`＝[ɿ]，齊齒前 `h` 寫 `x`（[ç]）；聲調 1 陰平、2 陽平、3 上、5 去、7 陰入、8 陽入。

## data/<方言點>/<方言點>.tsv

三欄精簡版：`字\t音標\t註釋`，首行為 `#漢字\t音標\t註釋`。便於匯入其他詞典工具。

## data/<方言點>/待辦清單.tsv

未決事項，一行一件：補字（有候選／無候選）、補音、改音。最後一欄為待填的決定。

## data/<方言點>/ 其餘依據檔

| 檔 | 內容 |
|---|---|
| `_provenance.tsv` | 每條讀音的出處（母本行號、抽取方式、原文） |
| `_簡繁.tsv` | 一簡對多繁的判定記錄 |
| `_errata.tsv` | 對母語者表的訂正（字、原拼、新拼、說明） |
| `_增補.tsv` | 人工增補的讀音 |
| `_本字回填.tsv` | 有音無字補出的本字 |
| `待考字表.tsv` | 有音無字、例句拼音的原始材料 |
