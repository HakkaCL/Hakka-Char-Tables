# 惠陽淡水

廣東惠陽淡水鎮塘邊村。母本《惠陽縣志》（2003）第三十七篇〈方言〉。1,053 條／991 字。

要點：

- 縣志詞表逐字對位；詞表以詞為單位，個別條目對位可能有誤，宜核原書。
- 泥來合流，都讀 l（腦 `lau3`＝老 `lau3`）。
- 遇三讀 iu（豬 `ziu1`、書 `siu1`）；三四等無 i 介音（天 `ten1`、月 `nged8`）。
- 原書調值 44／11／31／53／1／5 已換算為調類 1、2、3、5、7、8。

- 字形：母本簡體，本表先按釋義轉繁體、再補回簡體；簡繁兼收，`字形` 欄記 `繁`／`簡`／`通`，一簡對多繁時簡體字按對應的繁體字分列。
