# 惠東大嶺

廣東惠東大嶺鎮白沙布管理區。每行一個「字—讀音」，母本為《客家話通用詞典》（2004）各詞條後「惠」欄讀音。

| 欄 | 說明 |
|---|---|
| 字 | 繁體單字（母本用簡體，已轉繁體） |
| UCODE | 碼位 |
| 客拼 | 臺灣《客家語拼音方案》，聲調 1–8（母本已用調類代號 1 2 3 5 7 8） |
| 聲母 / 韻母 / 聲調 | 由客拼切分 |
| 音標 | IPA，聲調同用 1–8 |
| 來源 | `惠欄·全合`（整條與姊妹點旁證全合）／`惠欄·部分`（部分字有旁證）／`周日健1994`（補字）／`周日健1994·訂正`（改音） |
| 註釋 | 該字所出詞條；補字者為該文例詞 |

詞典以長汀、梅縣為收詞依據，惠東只是十二個代表點之一，故字數有限；另以周日健〈廣東省惠東客家方言的語綴〉（《方言》1994:2，同一調查點大嶺鎮白沙布）補 67 字，並訂正 3 條（簪、奈、夜）。共 723 條／685 字。

讀音塊有時改用同義詞（如［伯娓］惠作「阿娘」），已用旁證校驗擋下。
