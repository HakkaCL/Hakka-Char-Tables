# 惠東大嶺

廣東惠東大嶺鎮白沙布管理區。母本《客家話通用詞典》（2004）各詞條後「惠」欄讀音。959 條／914 字。

要點：

- 詞典以長汀、梅縣為收詞依據，惠東只是十二個代表點之一，故字數有限。
- 另以周日健〈廣東省惠東客家方言的語綴〉（《方言》1994 年第 2 期，同一調查點大嶺鎮白沙布）補 67 字，並訂正 3 條（簪、奈、夜）。
- 讀音塊有時改用同義詞（如［伯娓］惠作「阿娘」），已用旁證校驗擋下。
- 原書 `ɛ`／`ɔ` 依其音系表統一作 `e`／`o`。

- 字形：母本簡體，本表先按釋義轉繁體、再補回簡體；簡繁兼收，`字形` 欄記 `繁`／`簡`／`通`，一簡對多繁時簡體字按對應的繁體字分列。
