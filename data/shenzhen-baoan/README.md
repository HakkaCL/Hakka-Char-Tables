# 深圳寶安

廣東深圳寶安（舊寶安縣）。每行一個「字—讀音」，母本為《客家話大辭典》寶安腔網絡版（hakkadictionary.com）。

| 欄 | 說明 |
|---|---|
| 字 | 單字，照母本字形（多為繁體，含異體、俗字與擴展區字） |
| UCODE | 碼位 |
| 客拼 | 臺灣《客家語拼音方案》，聲調 1–8；方案無 y 字母，/j/ 記作零聲母的 i 韻頭 |
| 聲母 / 韻母 / 聲調 | 由客拼切分 |
| 音標 | IPA，聲調同用 1–8 |
| 來源 | `寶安腔辭典` |
| 註釋 | 母本的同音字注（如「本典同音字注：益」） |

要點：本點有音位性 /j/，客拼寫 i 韻頭（一 `id7`、爺 `ia2`、有 `iu1`）；ɿ 已併入 u（資 `zu1`）；流攝讀 iu（狗 `giu3`）。

客拼無 y，/j/ 與零聲母在客拼欄偶爾同形（如 有 `iu1` 與 歐 `iu1`），音標欄作 [j] 與 ∅ 之別，仍可分。
