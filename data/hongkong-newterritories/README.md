# 香港新界

香港新界原居民客家話（粵台片梅惠小片）。每行一個「字—讀音」，母本為香港本土語言保育協會（HKILANG）《發音字典》字音表，即 `github.com/hkilang/TTS` 的 `src/res/raw/dictionary.csv`；該表源於協會早年在新界各村所作調查，與圍頭話並列記錄。

| 欄 | 說明 |
|---|---|
| 字 | 單字，照母本字形 |
| UCODE | 碼位 |
| 客拼 | 臺灣《客家語拼音方案》，聲調 1–8；方案無 y 字母，/j/ 記作零聲母的 i 韻頭 |
| 聲母 / 韻母 / 聲調 | 由客拼切分 |
| 音標 | IPA，聲調同用 1–8 |
| 來源 | `HKILANG字典` |
| 註釋 | 母本例詞，`~` 代本字（如「~夫」「姨~」） |

要點：

- **六調**：陰平 1、陽平 2、上 3、去 5、陰入 7、陽入 8，無陽上、陽去。協會原表用 1–6（4 為去聲、5 陰入、6 陽入），本表已按調類換算。
- **有音位性 /j/**，客拼寫 i 韻頭，音標作 j：一 `jit7`、有 `jiu1`、音 `jim1`。客拼無 y 字母，故 有 `iu1` 與 歐 `iu1` 同形，音標以 `j-` 與零聲母區別。
- **三四等保留 i 韻頭**：天 `tien1` [tʰien]、月 `ngied8` [ŋiet]、仙 `sien1`；寶安、惠陽作 `ten1`、`nged8`、`sen1`。
- **流攝讀 eu**：頭 `teu2`、狗 `geu3`、樓 `leu2`（寶安作 iu）。
- **ɿ 併入 u**：資 `zu1` [tsu]、事 `su5`。
- 通攝 `ung/ug`、宕攝 `ong/og`：東 `dung1`、屋 `vug7`、光 `gong1`、角 `gog7`。
- **字形照母本**：以繁體為主，另有 117 個字頭經 OpenCC s2t 會變形（万、体、儿、党、听等）；其中 112 個另有繁體字頭並存，72 個讀音完全相同。本表照錄，未轉換、未合併，以免一簡對多繁（干／乾／幹、后／後）誤判。
- 原表「摑」作 `get3`（收 -t 尾而標舒聲調），旁證（寶安 `ged7`）作陰入，照收並在註釋標明。
