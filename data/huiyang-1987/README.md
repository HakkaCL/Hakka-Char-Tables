# 惠陽 1987

周日健〈廣東省惠陽客家話音系〉（《方言》1987 年第 3 期）表一至表五單音節表。1,227 條／1,206 字。

要點：

- 與《惠陽縣志》淡水點不是同一土語：本點泥母讀 n（男 `nam2`）、遇三讀 u（書 `su1`、手 `su3`），淡水讀 l、iu，故兩表並列，不相合併。
- 三四等作 `ian`／`iad`（天 `tian1`、乙 `iad7`）。
- 原書調值 44／11／31／53／1／5 已換算為調類 1、2、3、5、7、8；例字原以圖形記號標調，按同文 1.3 調值換算。
- 註釋為原書圈號說明（有音無字的注釋），無則空。
