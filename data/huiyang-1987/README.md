# 惠陽 1987

周日健〈廣東省惠陽客家話音系〉（《方言》1987:3）表一至表五單音節表。每行一個「字—讀音」。

| 欄 | 說明 |
|---|---|
| 字 | 繁體單字（原書簡體，已轉繁體） |
| UCODE | 碼位 |
| 客拼 | 臺灣《客家語拼音方案》，聲調 1–8 |
| 聲母 / 韻母 / 聲調 | 由客拼切分 |
| 音標 | IPA，聲調同用 1–8（原書調值 44/11/31/53/1/5 已換算） |
| 來源 | `周日健1987·表N`（表一至表五） |
| 註釋 | 原書圈號說明（有音無字的注釋），無則空 |

要點：本點與《惠陽縣志》淡水點不是同一土語——泥母讀 `n`（男 `nam2`）、遇三流三知章讀 `u`（書 `su1`、手 `su3`），淡水則讀 `l`、`iu`。故兩表並列，不相合併。
