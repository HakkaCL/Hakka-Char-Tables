# 大埔百侯

廣東梅州大埔百侯鎮。母本何耿鏞《客家方言詞典》（2012），另收作者田調與教育部《臺灣客家語書寫推薦用字》兩批。4,888 條／4,445 字。

要點：

- 簡繁兼收：每讀音繁、簡各一行，`字形` 欄記 `繁`／`簡`／`通`。一簡對多繁按義分列：干 `gon1`／`gon5` 對 乾 `gon1`、幹 `gon5`。
- 推薦用字條目在註釋標「台灣客家語書寫推薦用字（第 N 批）#編號」。
- 原書錯字已改正並在註釋註明；多音字每讀附例詞。
- 齊齒前 [ç] 寫 `x`、[ɛ] 寫 `ee`、舌尖元音寫 `ii`（見 [docs/schema.md](../../docs/schema.md)）。
