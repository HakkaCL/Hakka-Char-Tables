# 大埔百侯

廣東梅州大埔百侯鎮。母本何耿鏞《客家方言詞典》（2012），另收作者田調與教育部《臺灣客家語書寫推薦用字》兩批。3,701 條／3,371 字。

要點：

- 原書簡體，本表轉繁體；一簡對多繁（干／乾／幹、后／後）按釋義逐字判定。
- 推薦用字條目在註釋標「台灣客家語書寫推薦用字（第 N 批）#編號」。
- 原書錯字已改正並在註釋註明；多音字每讀附例詞。
- 齊齒前 [ç] 寫 `x`、[ɛ] 寫 `ee`、舌尖元音寫 `ii`（見 [docs/schema.md](../../docs/schema.md)）。

欄位見 [`docs/schema.md`](../../docs/schema.md)。
