# 大埔百侯

廣東梅州大埔百侯鎮的漢字讀音表。

## 檔案

| 檔 | 欄位 |
|---|---|
| `大埔百侯-完整表.tsv` | 字、UCODE、客拼、聲母、韻母、聲調、音標、來源、註釋 |
| `大埔百侯.tsv` | 字、音標、註釋（三欄精簡版） |

## 來源欄

- `詞典`：由《客家方言詞典》（何耿鏞，2012）整理
- `母語者表`：母語者田調
- `詞典、母語者表`：兩者一致

## 客拼方案

源於本地 Rime 輸入法方案，經整理：聲調 1–8；`b/p、d/t、g/k` 分不送氣/送氣；`ee`＝[æ]；`ii`＝[ɿ]/[ʅ]；齊齒前 `h` 寫 `x`。

## 說明

- 原書用簡體，本表轉為繁體，一簡對多繁者按釋義判定。
- 原書錯字已改正並在註釋留痕（如「坏像伙」→「坏傢伙」）。
- 有音無字的詞不在本表，另存於工作庫。
