# 興寧

廣東梅州興寧。母本饒秉才《興寧客家話詞典》（2017）附錄三〈伍 興寧話同音字表〉，逐頁對 300 dpi 頁圖校正後轉寫。6,068 條／5,191 字。

要點：

- **六調**：1 陰平 44、2 陽平 11、3 上 21、4 去 52、5 陰入 2、6 陽入 5；本表按調類換算為 1、2、3、5、7、8。
- **聲母 20**（含零聲母）：`b p m f v d t n l z c s zh ch sh rh g k ng h`；母本舌尖後音 `tʂ tʂ' ʂ ʐ` 依方案寫 `zh ch sh rh`。
- **韻母 40**，另成音節 `m`、`ng`：陰聲、陽聲、入聲齊備，入聲收 `-b -d -g`。
- `ɿ` 寫 `ii`（資 `zii1`）、`ʅ` 寫 `i`（知 `zhi1`）；`ɔ` 寫 `o`（哥 `go1`）。
- `來源` 兩個取值：`同音字表`（主體）、`單字詞條`（表未收、由正文單字詞條補入 212 字）。

已知：

- 「十」未收——同音字表、音序索引、正文單字詞條均未見，待回圖確認它排在哪一韻。
- 「唔」除 `m2` 外另有 `ngang1`（母本「唔（對；合適）」一讀），非誤收。
