# 長汀

福建龍巖長汀。母本周存《長汀話詞典》（2023）正文逐條注音。5,932 條／4,921 字。

要點：

- **五調**：1 陰平 33、2 陽平 24、3 上 42、4 陰去 54、5 陽去 21，無入聲。本表按調類換算為 1、2、3、5、6；7、8 空置。
- **聲母 23**（含零聲母）：`b p m f v d t n l z c s j q x zh ch sh g k ng h`。其中 `j q x` = [tɕ tɕʰ ɕ]、`zh ch sh` = [tʃ tʃʰ ʃ]，兩套分立，均為《客家語拼音方案》原有符號。
- **o / oo 分立**（依方案）：`o` = [o]、`oo` = [ɔ]。母本 `ɑo`→`oo`、`iɑo`→`ioo`、`ônɡ`→`oong`、`iônɡ`→`ioong`；`onɡ` [oŋ] 仍寫 `ong`、`ionɡ` 寫 `iong`。故長汀的 `ioong` 對應梅惠的 `iong`（宕攝），`iong` 對應梅惠的 `iung`（通攝）。
- **`ï` 寫 `ii`**：在 `z c s` 後為 [ɿ]（資 `zii1`），在 `zh ch sh` 後為 [ɨ]（時 `shii2`）。
- `來源` 兩個取值：`單字詞條`（主體）、`詞條`（多字詞逐位對齊、且有兩次以上佐證者）。

已知：

- 通攝三等多讀 `ong`（東 `dong1`、中 `zhong1`、風 `fong1`），`iong` 僅「凶、容」等少數；依母本，不按梅惠類推。
